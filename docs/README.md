# PROMAT Docs

Die Dokumentation ist in wenige stabile Bereiche gegliedert.

- `PROMAT_ Plattform-, Daten- und Filestruktur.md`: bindende Source of Truth für Zielarchitektur und Datenmodell.
- `architecture/`: aktive Architekturübersichten und Dev/Prod-Parität.
- `conventions/`: operative Repo-Konventionen und Benennungsregeln.
- `runbooks/`: wiederholbare Abläufe für Entwicklung und Betrieb.
- `decisions/`: dauerhafte Architekturentscheidungen.
- `agent-runs/`: substanzielle Änderungsprotokolle pro Run.
- `start/`: historische Bootstrap- und Strukturchronik.

Wenn aktive Doku und Spezifikation auseinanderlaufen, wird die aktive Doku korrigiert oder die Abweichung explizit dokumentiert.
