# Runbooks

Dieser Bereich enthält wiederholbare Dev- und Prod-relevante Abläufe.

Geeignet sind nur Prozesse, die andere Maintainer oder Agents mehrfach sicher nachfahren müssen, zum Beispiel Setup, Migration, Export oder Recovery.

Runbooks definieren nicht den Soll-Zustand; dieser steht in `docs/spec/`.

Nutze `_template.md` und halte Runbooks schrittgenau, aber knapp.
