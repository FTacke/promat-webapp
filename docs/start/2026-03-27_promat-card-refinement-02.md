# PROMAT Card Refinement 02

## Anlass

Verfeinerung des ruhigen Card-Systems nach dem ersten Sample-Aufbau.

## Ergebnis

- CTA in den Sample-Cards jetzt konsequent an die Unterkante gebunden
- Forschungs-Cards mit direkt unter dem Titel platzierter Meta-Zeile `Projekt-Leitung: ...`
- Lehr-Cards um subtile Sprach-Tönungen erweitert
- Forschungs-Cards einheitlich kühl getönt
- Innenabstände der `pm-card__body` leicht beruhigt

## Grenzen

- keine Änderungen an Admonitions
- keine Änderungen an Panels
- keine Hover-Lifts oder Schatten
