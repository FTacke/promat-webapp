# PROMAT Card Spacing Refinement 03

## Anlass

Feinschliff der Corpus- und Sprachkarten auf Mikro-Abstände und Abschlusszone.

## Ergebnis

- Titel, Meta, Beschreibung und CTA sind rhythmisch klarer getrennt
- Meta-Zeile unter dem Titel stärker vom Fließtext gelöst
- CTA-Zone optisch deutlicher als Abschluss lesbar
- Card-Body leicht gelockert, ohne die Karten aufzublähen

## Unveraendert

- keine Aenderung an Zeilenhoehe des Fliesstexts
- keine Aenderung an Admonitions oder Panels
- keine neuen Effekte, Schatten oder Hover-Lifts
