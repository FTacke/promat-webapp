# PROMAT Teaching Card Top Accent Refinement 05

## Anlass

Lehr-Cards sollten sich klar von Forschungskarten unterscheiden, ohne ueber Farbflächen lauter zu werden.

## Ergebnis

- Forschungs- und Lehr-Cards teilen nun dieselbe neutrale Raised-Surface-Grundlage
- sprachspezifische Hintergrundtoenungen wurden aus den Lehr-Cards entfernt
- Lehr-Cards unterscheiden sich stattdessen ueber einen kontrollierten Top-Akzent pro Sprache
- CTA-Farbe der Lehr-Cards ist an die jeweilige Sprache gekoppelt

## Unveraendert

- keine Aenderung an Card-Geometrie oder Grid
- keine Hover-Lifts, keine neuen Icons, keine starken Schatten
- Forschungskarten bleiben bewusst neutral ohne Farb-CTA
