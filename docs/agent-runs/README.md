# Agent Runs

Dieser Bereich enthält die nicht-normative Chronik substantieller Agent- oder Maintainer-Runs.

## Wann ein Eintrag nötig ist

- bei Architektur-, Routing-, Runtime-, Datenpfad-, Governance- oder Doku-Strukturänderungen
- bei Änderungen, die mehrere Bereiche des Repos berühren
- bei Änderungen, die Dev/Prod-Parität, Benennungen oder aktive Regeln beeinflussen

## Format

- Dateiname: `YYYY-MM-DD_kurzer-slug.md`
- Grundlage: `_template.md`
- Sprache: knappes, repo-spezifisches Deutsch

## Mindestinhalt

- Ziel des Runs
- konsultierte Source-of-Truth-Dokumente
- geänderte Bereiche
- wichtige Entscheidungen
- Abweichungen von der Spezifikation oder Parität
- Verifikation
- offene Punkte
- nächste sinnvolle Schritte

Run-Logs sind nie Source of Truth. Aktive Regeln gehören immer in `../spec/`.
